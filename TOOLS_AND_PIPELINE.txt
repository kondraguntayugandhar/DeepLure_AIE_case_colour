------------------------------------------------------------------------------
1. TOOLS AND TECHNOLOGIES USED
------------------------------------------------------------------------------
- PyTorch (torch, torch.nn, torch.amp):
  The core deep learning framework used to build, train, and evaluate the neural
  network model. It handles tensor computations, automatic differentiation, and GPU
  acceleration.

- Torchvision (torchvision.models, torchvision.transforms):
  Provides the pretrained ResNet-50 backbone model weights and data augmentation
  pipeline (ColorJitter, RandomGrayscale, RandomResizedCrop, Normalization).

- Scikit-Learn (sklearn.metrics):
  Used to compute quantitative evaluation metrics: Precision, Recall, F1 Score,
  ROC-AUC, and Confusion Matrix.

- Pillow / PIL (PIL.Image):
  Python Imaging Library used for safe RGB image loading, decoding, and preprocessing.

- NumPy (numpy):
  Used for numerical matrix operations, threshold array generation, and stats calculations.

- Matplotlib (matplotlib.pyplot):
  Used for visual plotting of dataset distribution histograms and image grids.

- Python Standard Library (pathlib, re, hashlib, json, collections):
  Used for exact image duplicate detection via MD5 hashing, regex base design ID
  extraction, zero-leakage dataset splitting, and JSON metadata saving.

- Git & GitHub:
  Version control system used to track code edits, ignore large image datasets via
  .gitignore, and push the repository to GitHub.

------------------------------------------------------------------------------
2. TECHNICAL PIPELINE BREAKDOWN
------------------------------------------------------------------------------

[STAGE 1: DATA CLEANING & ZERO-LEAKAGE SPLITTING]
- The pipeline scans images from both 'archive' (1,468 images) and 'handlooms' (165 images),
  totaling 1,633 images across 775 unique design identities.
- Filenames are cleaned using regular expressions to strip Roboflow augmentation suffixes
  (_jpg.rf.<hash>).
- Images are grouped strictly by base design identity.
- Data is split 70% Train (542 designs), 15% Validation (116 designs), and 15% Test
  (117 designs) to guarantee ZERO DATA LEAKAGE across splits.

[STAGE 2: COLOR-INVARIANT AUGMENTATIONS]
- Input images are resized to 224x224 RGB tensors.
- Training augmentations destroy color dependence while preserving textile weave geometry:
  * ColorJitter (brightness, contrast, saturation, hue changes)
  * RandomGrayscale (p=0.25): forces network to learn motif geometry instead of color
  * RandomResizedCrop (scale 0.6 to 1.0)
  * RandomHorizontal/Vertical Flips & Small Rotations (+/- 15 degrees)

[STAGE 3: MODEL ARCHITECTURE]
- Input: 224x224x3 RGB image tensor
- Backbone: Pretrained ResNet-50 (removes final 1000-class classification layer) -> outputs 2048-D features
- Projection Head: Linear(2048 -> 512) -> BatchNorm1d -> ReLU -> Linear(512 -> 128)
- L2 Normalization: Normalizes output vector z onto a unit hypersphere (||z||_2 = 1)
- Output: 128-dimensional L2-normalized embedding vector.

[STAGE 4: LOSS FUNCTION (SUPERVISED CONTRASTIVE LOSS)]
- Supervised Contrastive Loss (SupCon, temperature tau=0.07):
  Pulls all positive colorways/shots of the same saree design together in feature space
  while pushing different saree designs apart.

[STAGE 5: INFERENCE, RETRIEVAL & VERIFICATION]
- Gallery Indexing: Computes 128-D embeddings for reference gallery images.
- Cosine Similarity Retrieval: Dot product between query embedding q and gallery embeddings Z_gallery
  retrieves top-5 matches.
- Pairwise Verification: Compares dot product similarity between two image embeddings against an
  empirically tuned validation threshold (tau* = 0.820). If similarity >= 0.820, predicts "Same Design".
